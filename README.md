<h1>🔐 Week 3: Password Cracking</h1>

<h2>📌 Project Overview</h2> 
This Week 3 project focused on understanding how password cracking works and why strong passwords are important in cybersecurity.
I completed two practical modules:
W3-PM1: Password Cracking with JTR
W3-PM2: Password Cracking with Networkwalks Tools
The exercises involved recovering the password of a protected PDF in an authorized learning environment. W3-PM1 - Week3 - Project Module1 - Password Cracking with JTR v1.pdf

<h2>🎯 Objectives<h/2>
The main objectives of this project were to:
Understand how password cracking works.
Learn how password hashes are extracted from protected files.
Use John the Ripper to perform password recovery.
Use Johnny, the graphical version of John the Ripper.
Use the Networkwalks Hash Calculator.
Use the Networkwalks Password Cracker.
Understand the importance of strong passwords.
Practice password-cracking techniques in a controlled environment.

<h2>🛠️ Module 1: Password Cracking with JTR</h2>
For the first module, I used John the Ripper (JTR) and Johnny to recover the password of a protected PDF.
John the Ripper is a password-cracking tool used by security professionals to test password strength. Johnny provides a graphical interface that makes JTR easier to use. W3-PM1 - Week3 - Project Module1 - Password Cracking with JTR v1.pdf

<h2>🔹 Tasks Completed</h2>
Installed John the Ripper on Windows.
Installed and configured Johnny.
Located and selected john.exe.
Extracted the hash from the protected PDF.
Saved the hash in a text file named hash1.txt.
Loaded the hash file into Johnny.
Started a password-cracking attack.
Used the recovered password to open the protected PDF. W3-PM1 - Week3 - Project Module1 - Password Cracking with JTR v1.pdf W3-PM1 - Week3 - Project Module1 - Password Cracking with JTR v1.pdf

<h2>🌐 Module 2: Password Cracking with Networkwalks Tools</h2>
For the second module, I used the online Networkwalks Hash Calculator and Password Cracker.
These tools work through a web browser, so no additional software installation was required. W3-PM2 - Week3 - Project Module2 - Password Cracking with NW Tools v1.pdf

<h2>🔹 Tasks Completed</h2>
Uploaded the protected PDF to the Networkwalks Hash Calculator.
Extracted the PDF hash.
Copied the complete hash beginning with $pdf$.
Entered the hash into the Networkwalks Password Cracker.
Started the password-cracking process.
Waited for the password to be recovered.
Used the recovered password to open the PDF. W3-PM2 - Week3 - Project Module2 - Password Cracking with NW Tools v1.pdf W3-PM2 - Week3 - Project Module2 - Password Cracking with NW Tools v1.pdf
